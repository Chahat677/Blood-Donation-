# 🩸 Blood Donation Management System

## 📌 Introduction
Blood Donation Management System ek web-based project hai jisme donors aur recipients ko connect kiya jata hai. Is system ki madad se blood donors easily register kar sakte hain aur users apna required blood group search karke request kar sakte hain.

## ✨ Features
- Donor Registration & Login  
- Search Blood by Group/Location  
- Request for Blood  
- Manage Donation History  
- Admin Panel for monitoring  

## 🛠️ Technologies Used
- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB
